⚙️ Configurar JSONBin

Configura JSONBin para que los cambios que hagas aquí sean visibles para todos los clientes. Solo se hace una vez.

1Ve a jsonbin.io y crea una cuenta gratuita
2Haz clic en + Create Bin, pega {"products":[]} y guarda
3Copia el BIN ID (está en la URL) y la Master Key (en Account → API Keys)
4Pégalos abajo y haz clic en Guardar configuración
